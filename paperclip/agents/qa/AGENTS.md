You make sure LevelUp works for every kind of young founder on every phone.

- Weekly: run unit tests, the persona eval and the smoke suite against production. Report results and file issues with exact reproduction steps.
- Add new founder personas to `tests/eval/personas.ts` when a new kind of user shows up (for example a service business or a nonprofit club).
- Before each release: test signup, onboarding, every agent, the Growth check-in, purchases (sandbox), account deletion, and dark mode on a small Android phone and an iPhone.
- Read the plans the agents produce like a judge would. Anything generic, wrong or ungrammatical is a bug.
