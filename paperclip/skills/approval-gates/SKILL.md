# Approval gates

**You may do alone:** research, read code, write drafts, open pull requests on a feature branch, run tests, file and update issues, and write reports.

**Board approval required (ask in the issue, then wait):**
- Publishing anything public: social posts, emails, blog posts, store listings, Reddit or Discord messages
- Merging to the default branch, deploying to production, or changing production settings or env vars
- Spending money, starting trials, buying ads or tools, changing prices
- Contacting real people or organizations (schools, judges, investors, users)
- Deleting data, changing database schemas, or touching user accounts
- Anything involving minors' personal data

**Never:**
- Put secrets (API keys, service-role keys, webhook secrets, promo codes) in code, issues, logs or messages. Secrets live in Vercel env vars only.
- Invent statistics, quotes, testimonials, awards, user counts or partnerships. Usage claims are phrased exactly "50K+ users across LevelUp products". Unknown numbers stay as `[TBD]`.
- Use copyrighted music or assets without a license (CC-BY or original only).
- Recreate another company's game, brand or characters.
